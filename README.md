# hack-a6d204dd-agentforge

Hackathon team repository for AgentForge

## FAQ-бот для репетиции хакатона

Небольшой терминальный бот на Node.js и TypeScript. Он читает пять пар вопрос–ответ из `faq.txt` и отвечает на вопросы о времени репетиции, команде, треке, сдаче проекта и призах. Если подходящей темы нет, бот выводит `не знаю`.

## Установка и запуск

Нужен Node.js 20+.

```bash
npm install
npm start
```

`npm start` сначала собирает TypeScript, затем запускает чат. Отдельная сборка:

```bash
npm run build
npm start
```

Для проверки тестов:

```bash
npm test
```

Примеры вопросов: `Когда начинается репетиция?`, `Во сколько встречаемся?`, `команда`, `Куда сдавать проект?`, `Какие призы?`. Вопросы можно задавать последовательно в одной сессии; для выхода нажмите `Ctrl+C`.

## Как выбирается ответ

Бот приводит вопрос к нижнему регистру, убирает знаки препинания и служебные слова, затем сравнивает оставшиеся слова с ключевыми словами каждого вопроса в `faq.txt`. Выбирается FAQ с наибольшим числом совпадений. Если совпадений нет, ответ — `не знаю`. Никакие внешние API или AI-модели не используются.
